## Task 2 — animated look cards, one shared component

New `look_card.js` + `look_card.css`: given a style *definition* (the JSON
`GET /api/styles` already returns), builds a small sample `.ass` in the
browser — a 3-word phrase exercising entrance, the active-word effect, and
exit — using the exact tag formulas in `styles/render.py` /
`styles/ass_format.py` / `styles/render_glow.py` (read, not imported: JS
can't import that package, so this is a deliberate, commented port, kept
honest by naming its source). Drives it through JASSUB in **canvas mode**
(`{canvas, subContent}`, no `<video>` — JASSUB supports this directly) so no
render-preview job, no ffmpeg, no per-card network round trip is needed.

Cost control: a fixed-size pool (4) of JASSUB instances is created once,
each owning one `<canvas>` whose WASM worker is never recreated. An
`IntersectionObserver` assigns pool slots to cards as they scroll into
view (moving that slot's `<canvas>` DOM node into the card and calling
`setTrack` on the existing renderer) and frees the slot when a card leaves
view, reverting that card to a static CSS poster (the same word-swatch
markup `style_editor.js`/`studio_looks.js` already build, factored into
`look_card.js` so there is exactly one implementation). A single shared
`requestAnimationFrame` loop drives every active pool slot's
`setCurrentTime`, looping a 2-second cycle.

`style_editor.html` gets the two new `<script>`/`<link>` tags directly
(mine to edit) plus `vendor/jassub/jassub.umd.js`, which it doesn't load
today. `studio.html` is off limits, so `studio_looks.js` injects
`look_card.js`/`look_card.css` at runtime if `window.AshLookCard` isn't
already defined (jassub.umd.js is already loaded there).

Test: `tests/test_web/js/look_card.test.mjs`, run with `node --test`
(no framework needed — Node 24 ships one) against the pure ASS-builder
functions (exported for the test via a tiny `module.exports` guard at the
bottom of `look_card.js`, inert in the browser): entrance/exit tag shape
for fade/rise/slide, active-word tag shape for pop/box/scale_box/card_box/
karaoke/shake/glow, matching the Python formulas byte for byte on a fixed
style fixture. Wired into the Python suite through a thin
`tests/test_web/test_look_card_js.py` that shells out to
`node --test tests/test_web/js/look_card.test.mjs` and skips if `node`
isn't on PATH, so `pytest tests -q` still exercises it in this repo's real
environment (Node 24 is present) without hard-depending on Node.
